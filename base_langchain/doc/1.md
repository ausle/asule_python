## pip安装第三方依赖时需要注意的问题
pip install -r .\requirements.txt
会安装requirements.txt中列出的第三方依赖。
安装位置由pip属于哪个python环境决定，我的pip所在的位置是：D:\software\Python310\Scripts\pip.exe。
项目会安装在：D:\software\Python310\Lib\site-packages。（site-packages是python第三方依赖包存放目录）。
这种方式是全局的安装，有可能会污染其他的python项目，更值得推荐的做法是：

更加建议是在虚拟环境进行安装，避免影响其他的python项目：
```
先激活虚拟环境：
D:\code_python\python_study\.venv\Scripts\Activate.ps1
进行安装：
python.exe -m pip install -r .\base_langchain\chapter02\article_generator\requirements.txt

```
